# ESP32-C3 Super Mini: посадочное место

Ветка `f1q-esp32-c3-super-mini`. Контроллер устанавливается непосредственно
в **два ряда по 8 отверстий**, а не подключается пучком проводов.

| Размер | Значение |
|---|---:|
| Шаг контактов в ряду | 2,54 мм |
| Между осями рядов | 15,24 мм |
| Между первым и последним контактом ряда | 17,78 мм |
| Габарит самой платы по опубликованному чертежу | 18 × 22,52 мм |

Источник размеров и фото: [ArtronShop, документация Super Mini, стр. 2–3](https://dl.artronshop.co.th/ESP32-C3%20SuperMini%20datasheet.pdf).
Размер 17,78 мм вычислен как 7 интервалов по 2,54 мм.
Выступ USB-разъёма и место для кабеля учитываются отдельно от габарита платы.

**Вид со стороны компонентов, USB вверх:**

| Ряд сверху вниз | Слева | Справа |
|---:|---|---|
| 1 | GPIO5 | 5V |
| 2 | GPIO6 | GND |
| 3 | GPIO7 | 3V3 |
| 4 | GPIO8 | GPIO4 |
| 5 | GPIO9 | GPIO3 |
| 6 | GPIO10 | GPIO2 |
| 7 | GPIO20 | GPIO1 |
| 8 | GPIO21 | GPIO0 |

Цветной рисунок распиновки на стр. 2 показывает противоположную сторону:
его нельзя без зеркального преобразования переносить на верхний слой платы.
Ориентация выше сверена с фото компонентов и подписей на стр. 3.
Перед изготовлением приложить свой модуль к распечатке 1:1 и сверить 5V/GND/3V3:
под названием Super Mini продаются разные ревизии и клоны.

## Назначение выводов F1Q

| Функция | GPIO |
|---|---:|
| Servo S / R / W | 4 / 5 / 6 |
| Сигнал ESC | 3 |
| ARM / START | 0 / 1 |
| RC DT / OFF | 7 / 20 |
| Управление активной пищалкой через драйвер | 21 |
| Встроенный синий LED, активный низкий уровень | 8 |
| SDA / SCL INA226 и BMP280 | 2 / 10 |
| BOOT — не подключать к периферии | 9 |

GPIO18/19 заняты USB; GPIO11–17 здесь не используются.
GPIO2 получает подтяжку SDA к 3,3 В. GPIO8 используется только для встроенного LED.
Ограничения загрузочных GPIO сверены с [документацией ESP32-C3, раздел 3](https://www.espressif.com/sites/default/files/documentation/esp32-c3_datasheet_en.pdf).
GPIO21 может передавать сообщения ROM при включении: возможен короткий звук
внешней активной пищалки. На этот вывод нельзя переносить ESC.

Концевики BACK/FRONT относятся к F1A и в этой ветке отсутствуют.
Wi-Fi включается при старте со снятым ARM на три минуты; повторное включение —
снять ARM и держать OFF три секунды. Конфигурация F1Q изначально выключена:
в таком состоянии разрешена настройка, автоматического запуска по крючку нет.
